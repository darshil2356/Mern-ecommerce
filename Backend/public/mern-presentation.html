Authentication Module — Deep Dive

04 / 23
1
POST /api/user/register — Validate mobile is unique → bcrypt.hash(password, 10) → Save user → Auto-generate referral code using nanoid(8) → If referralCode query param present, find referrer and set referredBy
2
POST /api/user/login — Find user by mobile → Check isBlocked → user.isPasswordMatched(password) → Sign JWT: jwt.sign({id, role}, JWT_SECRET, {expiresIn:"24h"}) → Generate refresh token → Store in DB → Return both tokens
3
authMiddleware (every protected route) — Extract Bearer token from Authorization header → jwt.verify(token, JWT_SECRET) → Decode user id → User.findById(id).select("-password") → Attach req.user → Call next()
4
isAdmin middleware — Check req.user.role === "admin" → If false → throw new Error("Not authorized as admin") with status 403 → Chain: route → authMiddleware → isAdmin → controller
5
POST /api/user/refresh-token — Receive refresh token → Find user with matching refreshToken in DB → Verify validity → Issue new JWT (24h) → Return new access token
6
Forgot Password — crypto.randomBytes(32).toString("hex") → SHA-256 hash stored in DB → Raw token sent via Nodemailer email → Link: /reset-password/:token → 30-minute expiry → On reset: hash incoming token → compare with DB hash → verify expiry → update password

ReferralConfig Model

{ isEnabled: Boolean, rewardTrigger: "ON_SIGNUP" | "ON_FIRST_PURCHASE" | "ON_EVERY_PURCHASE", rewardType: "FIXED_COINS" | "PERCENTAGE", fixedCoins: Number, percentage: Number, minPurchaseAmount: Number, maxRewardPerUserPerMonth: Number, enableFirstPurchaseReward: Boolean, enableEveryPurchaseReward: Boolean }

processReferralReward() Logic

1
Load ReferralConfig + CoinConfig from DB
2
Check if buyer has referredBy → if yes, find referrer user
3
Check rewardTrigger → ON_SIGNUP = already awarded at registration → ON_FIRST_PURCHASE = check if this is buyer's first order → ON_EVERY_PURCHASE = always
4
Calculate coins: FIXED_COINS = fixedCoins directly; PERCENTAGE = (orderAmount × percentage) / 100
5
Monthly cap check: count coinTransactions where source="referral_purchase" and createdAt within current month → remaining = maxReward - currentMonthTotal
6
Award min(calculatedCoins, remaining) to referrer → push coinTransaction → increment referralCount and referralEarnings
7
Also call processPurchaseReward() to award buyer coins for their own purchase

awardCoins() Function

async function awardCoins(userId, coins, reason, source, description, metadata = {}) { const user = await User.findById(userId); const config = await CoinConfig.findOne(); if (!config?.isEnabled) return 0; // Monthly cap for purchase rewards const monthStart = new Date(new Date().getFullYear(), new Date().getMonth(), 1); const monthTotal = user.coinTransactions .filter(t => t.source === source && t.createdAt >= monthStart) .reduce((s, t) => s + t.coins, 0); const remaining = config.purchaseMaxCoinsPerOrder - monthTotal; const finalCoins = Math.min(coins, Math.max(remaining, 0)); user.coins += finalCoins; user.coinTransactions.push({ type: "credit", coins: finalCoins, reason, source, description, metadata, createdAt: new Date() }); await user.save(); return finalCoins; }

async function deductStock(orderItems) { for (const item of orderItems) { const product = await Product.findById(item.product); if (product.variants?.length > 0) { // Level 3: Find variant by color → find size → deduct const variant = product.variants.find( v => v.color.toString() === item.color.toString() ); const sizeEntry = variant.sizeStock.find( s => s.size === item.selectedSize ); sizeEntry.quantity -= item.quantity; } else if (product.sizeStock?.length > 0) { // Level 2: Find size → deduct const sizeEntry = product.sizeStock.find( s => s.size === item.selectedSize ); sizeEntry.quantity -= item.quantity; } else { // Level 1: Simple deduction product.quantity -= item.quantity; } // Recalculate total quantity product.quantity = recalcTotal(product); await product.save(); } }

Security Architecture — Deep Dive

Authentication Layer

JWT
Signed with JWT_SECRET (env var) → 24h expiry → payload: {id, role} → stored in localStorage on frontend
RT
Refresh Token stored in DB → issued at login → verified on /refresh-token → issues new JWT without re-login → can be revoked
PW
Bcrypt with salt rounds: 10 → bcrypt.hash(password, 10) → never stored in plain text → select: false on schema

Authorization Middleware Chain
